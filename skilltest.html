08 Dark / Light Mode Toggle

다크/라이트
모드 토글

localStorage에 테마를 저장해 새로고침 후에도 유지합니다. data-theme 속성 변경으로 CSS 변수 전체를 한번에 교체합니다.

theme-toggle.js
// 초기 로드 — 저장값 없으면 dark 기본
const saved = localStorage.getItem('theme') || 'dark';
document.documentElement
  .setAttribute('data-theme', saved);

// 토글 버튼
themeToggle.addEventListener('click', () => {
  const current = document.documentElement
    .getAttribute('data-theme');
  const next = current === 'dark'
    ? 'light' : 'dark';
  document.documentElement
    .setAttribute('data-theme', next);
  localStorage.setItem('theme', next);
});

12 Footer & Daangn Deeplink

푸터 구성
& 딥링크

당근마켓은 앱 전용 서비스로 웹 URL이 없습니다. daangn:// 딥링크 + 미설치 시 스토어로 분기합니다.

USER AGENT 확인 iOS / Android / 기타 판별
→
딥링크 시도 daangn://로 앱 열기 시도
→
1.5초 후 fallback 미설치 시 App Store / Play Store
→
PC daangn.com 새 탭 오픈
daangn-deeplink.js
function openDaangn() {
  const isIOS     = /iPhone|iPad|iPod/i.test(navigator.userAgent);
  const isAndroid = /Android/i.test(navigator.userAgent);
  const appStore  = 'https://apps.apple.com/kr/app/...';
  const playStore = 'https://play.google.com/store/...';

  if (isIOS) {
    window.location.href = 'daangn://';
    setTimeout(() => { window.location.href = appStore; }, 1500);
  } else if (isAndroid) {
    window.location.href = 'daangn://';
    setTimeout(() => { window.location.href = playStore; }, 1500);
  } else {
    window.open('https://www.daangn.com/', '_blank', 'noopener');
  }
}
13 Troubleshooting

트러블슈팅
메모

제작 과정에서 마주친 12가지 버그와 해결 방법입니다.

문제 원인 해결
<strong> flex 분리 li에 display:flex → inline이 flex item화 <span>으로 감싸기
다크모드 제목 불가시 color:var(--dark)가 고정값 var(--text-heading) 토큰 사용
버튼 텍스트 다크 안 보임 color:var(--white)가 다크에서 #0F172A color: #fff 고정값 사용
한국어 단어 중간 줄바꿈 CSS 기본 word-break word-break: keep-all 전역 적용
마크다운 ** 그대로 출력 textContent로 설정 renderMarkdown() 함수 적용
가격 카드 텍스트 안 보임 인라인 color:#fff 라이트에서 그대로 .price-tier:not(.featured) p { color: var(--gray-700) !important }
모달 부제목 웨이브에 가림 ::after 웨이브가 텍스트 위에 렌더링 ::after에 z-index:0, 헤더 padding-bottom:48px
OS select 모달 밖으로 브라우저 네이티브 UI는 z-index 불가 커스텀 div 드롭다운으로 교체
수강신청 재열 시 내용 남음 openModal()에서 폼 초기화 안 함 openModal()에 value/classList 초기화 추가
eyebrow 다크 대비 부족 #4F46E5 on #1E293B = 2.7:1 [data-theme="dark"] .eyebrow { color: #a5b4fc }
당근 링크 웹 없음 당근은 앱 전용 서비스 daangn:// 딥링크 + 미설치 시 스토어
데모 카드 라이트 안 보임 인라인 color:#fff 고정 .dc-title, .dc-sub, .dc-hint 클래스로 교체
